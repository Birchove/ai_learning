# **狼人杀多智能体系统**
## 一、需求分析（发给 AI 的第一条消息）
我要用 Python 实现一个多智能体狼人杀游戏系统，支持以下功能：

1. 支持标准6人局：2狼人、1预言家、1女巫、1猎人、1村民。
2. 每个角色由独立的大语言模型 Agent 控制，Agent 具备决策、发言、投票能力。
3. 游戏流程严格按照狼人杀规则：夜晚→狼人刀人→预言家查验→女巫行动→天亮→公布死亡→发言→投票→放逐→循环，直到某一方胜利。
4. 信息隔离：狼人知晓同伴，但不清楚神职；好人不知道任何人身份；神职只有自己的技能信息。
5. 每个 Agent 可以有不同的决策风格（大胆、谨慎、平衡、随机），风格影响其发言和行动。
6. 游戏过程需要记录结构化日志（JSON），包含每一阶段的动作、发言、投票、死亡等，用于复盘。
7. 提供 FastAPI 接口，支持创建游戏、单步执行（step）、获取状态、删除游戏。
8. 提供简单的 Vue 前端观战台（可选），能实时展示游戏过程和控制步进。

请帮我设计项目结构、定义数据模型、编写核心类的代码骨架，并给出测试用例。
## 二、技术选型与约束定义（AI 的回答）
### 技术栈
- 语言：Python 3.10+
- Web 框架：FastAPI + Uvicorn
- 大模型接口：OpenAI 兼容 API（使用通义千问 qwen-max 或 GPT-4o-mini）
- 数据验证：Pydantic v2
- 前端：Vue 3 + Vite + Axios
- 日志与存储：JSON 文件 + Python logging
- 测试：pytest + pytest-asyncio

### 架构原则（架构宪法）
1. **信息隔离**：任何 Agent 在决策时只能访问其角色允许的信息（狼人可见同伴，预言家只知道查验结果，女巫知道死亡信息但不知身份）。
2. **确定性引擎**：游戏状态机由人工编写的 GameEngine 控制，严禁 AI 产生非法行动（如死而复生、连投两票）。
3. **可观测性**：每一轮决策都必须记录 reasoning（内心独白）和最终 action。
4. **模块解耦**：Agent 与游戏引擎通过标准接口通信，易于替换不同模型或规则。
5. **测试先行**：每个关键组件必须有对应的单元测试和集成测试。

from pydantic import BaseModel
from enum import Enum
from typing import List, Optional, Dict
from datetime import datetime

class Role(str, Enum):
    WEREWOLF = "werewolf"
    SEER = "seer"
    WITCH = "witch"
    HUNTER = "hunter"
    VILLAGER = "villager"

class Style(str, Enum):
    BOLD = "bold"        # 大胆：主动跳身份、强势带队
    CAUTIOUS = "cautious" # 谨慎：隐藏信息、跟风发言
    BALANCED = "balanced" # 平衡
    RANDOM = "random"     # 随机：故意迷惑对手

class PlayerState(BaseModel):
    id: int
    name: str
    role: Role
    style: Style
    is_alive: bool = True
    is_witch_saved: bool = False   # 女巫是否用过解药
    is_witch_poisoned: bool = False # 女巫是否用过毒药
    is_hunter_shot: bool = False    # 猎人是否已开枪
    # 其他状态如警长、投票等可扩展

class Dialogue(BaseModel):
    day: int
    phase: str          # "night_kill", "night_seer", "night_witch", "speech", "vote"
    player_id: int
    action: str         # "kill", "check", "save", "poison", "speech", "vote"
    content: Optional[str] = None
    target: Optional[int] = None
    reasoning: Optional[str] = None   # LLM 的思考过程

class GameRecord(BaseModel):
    game_id: str
    start_time: datetime
    end_time: Optional[datetime] = None
    config: str = "standard_6"
    players: List[PlayerState]
    dialogues: List[Dialogue] = []
    death_order: List[Dict] = []   # {"player_id": int, "day": int, "cause": str}
    winner: Optional[str] = None   # "good" or "evil"
```

        self.player_id = player_id
        self.name = name
        self.role = role
        self.style = style
        self.model = model
        self.client = OpenAI(
            base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
            api_key="your-api-key"
        )
        self.history = []   # 保存该玩家看到的所有公共对话

    def _call_llm(self, prompt: str) -> str:
        response = self.client.chat.completions.create(
            model=self.model,
            messages=[{"role": "user", "content": prompt}],

        )

from agent.base_agent import BaseAgent
from schema.models import Role

class WolfAgent(BaseAgent):
    def __init__(self, player_id, name, style, teammates_ids):
        super().__init__(player_id, name, Role.WEREWOLF, style)
        self.teammates = teammates_ids   # 狼人知道同伴

    def decide_action(self, game_state: Dict, available_actions: List[str]) -> Dict:
        if "night_kill" in available_actions:
            # 狼人商量杀人：实际工程中需要所有狼人投票，这里简化
            prompt = f"""
            你是狼人，队友有{self.teammates}。存活玩家：{game_state['alive_players']}。
            请选择今晚要杀的人，只返回玩家ID。风格：{self.style.value}
            """
            target = int(self._call_llm(prompt))
            return {"action": "night_kill", "target": target}
        elif "speech" in available_actions:
            content = self.speak(game_state)
            return {"action": "speech", "content": content}
        elif "vote" in available_actions:
            target = self.vote(game_state['alive_players'])
            return {"action": "vote", "target": target}
        else:
            return {"action": "pass"}

### 5.4 FastAPI 接口（api/server.py 片段）
```
from fastapi import FastAPI, HTTPException
from engine.session_manager import GameSessionManager
from schema.models import CreateGameRequest

app = FastAPI()
manager = GameSessionManager()

@app.post("/games")
async def create_game(req: CreateGameRequest):
    game_id = manager.create_game(req.config_name, req.player_styles)
    return {"game_id": game_id, "phase": manager.get_phase(game_id)}

@app.post("/games/{game_id}/step")
async def step_game(game_id: str):
    if not manager.has_game(game_id):
        raise HTTPException(404)
    state = manager.step(game_id)
    return state

@app.get("/games/{game_id}")
async def get_game_state(game_id: str):
    return manager.get_state(game_id)
