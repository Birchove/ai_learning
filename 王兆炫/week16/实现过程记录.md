以下记录开发AI狼人杀的一个实战过程

1. 了解狼人杀**规则**, 由于版本参差不齐, 所以筛选后选定使用12人标准局"预女猎白", 即便选定局型, 其版本也略有差异, 而后再确定一版具体的规则, 写为md文档, 放在主文件夹下
2. 收集狼人杀**攻略**, 并对齐为当前规则下的一些细节, 作为AI的学习资料, 这样真正游戏时, 各个角色的表现会更精彩
3. 首段提示词如下

```text
正如这个文件夹的名称所展示的, 我们目前要实现一个AI狼人杀的项目, 具体而言, 有这样一段描述, 是具体要求:
AI 狼人杀 — 多智能体协作与博弈的 Agent Team 实战 基于多 Agent 协作框架，构建一个能够自主完成信息不对称博弈的狼人杀 Agent Team 系统。 课题核心在于多智能体的协作/对抗与交互机制设计： 每个 Agent 根据其扮演角色（狼人、预言家、女巫等）拥有独立的目标、策略与行动空间，在严格信息隔离的约束下进行推理、发言与决策。系统需搭建完整的对局引擎，驱动回合流转与胜负裁决，并输出结构化日志以实现全程可观测。 加分项为前端观战 UI，支持纯 AI 对战或人机混战，直观呈现多 Agent 的实时博弈过程。 
进阶方向（三选一）：
1. 通用 Agent — 探索"读懂自己→修改自己→运行自己"的自演化系统，从「通用 Agent」演化为「狼人杀多角色 Agent」；
2. 评测+复盘 — 构建结果评测、过程评测等多维可量化评测体系，基于此完成任意游戏的复盘归因，并产出不同版本、不同模型 Agent 同台竞技的 Leaderboard；
3. 自进化 Agent — 实现"对局→分析→优化→再对局"自进化循环，使各角色 Agent 在多局迭代中持续提升胜率。


我们先宏观考虑, 即先不考虑进阶方向(但是需要为这个留有余地, 不能说基础版的实现无法扩展), 我现在已经收集整理好了两个md文档
1. @rules.md 因为狼人杀规则参差不齐, 所以我这里确定了一个标准版的规则, 同时, 把流传的不同版本进行了筛选整合, 我们项目的实现严格按照这个规则(另, 如果此规则在某些情况下有表述不清楚的方式, 请你指出, 我确定后修正对应规则, 应重点关注边界case, 尤其是角色特性与当前状态优先级不清楚时, 需要有明确的判断)
2. @game_guide.md 因为要增加游戏的趣味性, 以及精彩程度, 所以我搜集整理了这个攻略, 后续所有实现的智能体都应通读了解这个规则, 明确他们的对手可能采用什么方案, 以及他们自身可以采用什么方案, 同时可以有一些联想(另, 本文最后一个part介绍了一些狼人杀涉及的专业术语, 智能体在发言时可以采用这些术语, 同时规则介绍/攻略学习时遇到专业术语时也可以在这里查询)
以下几点是我的补充要求:
1. 因为狼人杀游戏一个很重要的事情就是信息的管理, 只有法官是全知视角, 其余玩家都必须严格按照规则来推理, 所以实现时要格外考虑这个点
2. 狼人杀的推理很大一部分来自发言和神态,动作, 所以智能体的每轮输出应至少包含: 当前模型, 玩家序号, 本局身份, 发言内容, 神态动作; 且玩家序号, 发言内容, 神态动作 可以被其余所有模型得知
3. 需要做好文件管理, 保证项目是条理且互不干扰的, 分卷时可以考虑上述的要求
4. 因为项目中提到了前端ui观战系统, 如何做好观战视角, 也是我们需要考虑的事情
5. 全流程你都需要和Claude Code协作, 每一步的进行你们都需要协商然后敲定一个最优的步骤进行, /claude-code-delegate  , 在开始之前, 别忘了严格按照格式生成CLAUDE.md, 以便于你们二人的协作
6. 目前只是plan, 我们先宏观安排步骤, 遵循tdd的开发原则, 即每一步的进行都不要破坏前面已有的流程, 所以plan很重要
```
